# 安全审计与合规披露

## 工具链审计结论（2026-11-08 实测，commit 8a13296）

- **accessory-location**（GPL-3.0，纯本地）：仅通过 USB 与 iPhone 通信（iAP2 配件协议），全库无遥测、无对外上传；APK 下载器带 SHA-256 固定校验，从不安装、从不运行 APK；认证助手无网络，只在本地对挑战值做 ECDSA P-256 签名
- 发送会话在项目自带沙箱 `tools/local-only.sb` 内运行（禁止对外 IP 联网），`send.sh` 已默认启用
- 依赖仅 `pymobiledevice3`（知名开源 iOS 通信库）与 `cryptography`；uv 与 venv 全部隔离在 `~/Library/Caches/accessory-location/`，不动用户全局 Python 环境

## MFi 身份来源（必须向用户如实披露）

- 身份文件（certificate.p7b / identity.pk8）提取自 DiPlay v0.2.7 预览 APK，其来源为**第三方从 Carlinkit 车载配件公开固件中恢复的生产 MFi 凭据**（见 DiPlay 仓库 THIRD_PARTY_NOTICES.md）
- 性质：借用其他厂商的苹果认证身份，属灰色变通；**苹果可能随时吊销该证书**（届时认证失败，按排障手册更新上游）
- 中国大陆的高血压通知等仍在监管审批中，本流程属提前尝鲜；健康结果仅供参考，不具医疗效力

## 红线（必须遵守）

1. **不得**把 identity.pk8 / certificate.p7b 打包进技能、复制给他人或上传任何地方；每次使用都通过固定 SHA-256 校验的 APK 现场提取，用完留在本机缓存目录
2. 仅限用户**本人设备**使用；不用于批量设备操作或商业代开
3. 推送会话结束后及时停止后台任务（按平台模板先核验归属再停止），不让发送器无期限运行
4. 对用户诚实披露风险：证书可能失效、系统更新可能封堵、健康提醒不能替代就医
5. 执行 `setup.sh` / `probe.sh` / `send.sh` 前，必须先向用户展示该步要下载的内容、写入路径与设备操作，取得明确同意；不得静默执行或代用户默认授权
